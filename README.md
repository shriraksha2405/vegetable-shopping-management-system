# Vegetable Shopping Management System

## Run
1. Install Python 3.10+.
2. Open terminal in this folder.
3. `python -m venv venv`
4. Windows: `venv\Scripts\activate`
5. `pip install -r requirements.txt`
6. `python app.py`
7. Open http://127.0.0.1:5000

## Payment
UPI and Card are simulated. The application stores only payment method, status and generated transaction ID; it does not collect card numbers, CVV, UPI PIN or banking passwords.
